# Features

This file used to hold a hand-kept checklist of every planned feature. It fell out of step with the code — almost every box was still unticked long after the features shipped — so it has been retired.

Where to look instead:

- **What MedBrains does today:** the capability summary in the [README](./README.md#what-it-does).
- **What is in progress and planned:** the [roadmap](./ROADMAP.md) and the [issues](https://github.com/DomnicAmalan/MedBrains/issues).
- **The full feature inventory** (about 2,200 rows, with priority, status and the web, mobile and TV surfaces each one needs): [`medbrains/apps/web/src/data/features.json`](./medbrains/apps/web/src/data/features.json), generated from the project's feature tracker.
- **How a module works:** the per-module RFCs under [`RFCs/`](./RFCs) and [`medbrains/RFCs/`](./medbrains/RFCs), and the user guide in [`medbrains/apps/docs`](./medbrains/apps/docs).
