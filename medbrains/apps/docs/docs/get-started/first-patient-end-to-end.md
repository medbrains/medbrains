# Your first patient, end to end

This walks one outpatient through the hospital. Each step names the role that
does it and links to the full guide.

## 1. Register the patient (receptionist)

Go to **Patients** → **Register Patient**, complete the five steps and select
**Register complete**. Keep **Send to OPD queue after registration** ticked:
the patient gets a token and an OPD visit.
[Full guide: register a patient](/user-guides/front-office/register-a-patient/).

## 2. Take vitals (nurse)

Go to **OPD Queue** → **Vitals counter**, select **Record vitals** on the
patient, enter the readings and select **Record vitals**. The patient is now
with the doctor.

## 3. See the patient (doctor)

1. In **OPD Queue**, select **Call patient** on the row, then **Start
   consultation**, then **Open OPD visit**.
2. Write and sign the consultation.
   [Full guide: write and sign a consultation](/user-guides/doctor/consultation/).
3. Open **Prescriptions**, add the medicines, check **Safety**, and select
   **Sign & save**.
4. Back in the queue, select **Complete**.

## 4. Dispense (pharmacist)

1. Go to **Pharmacy** → **Rx Queue** and select **View prescription**.
2. Check the lines and prices, then select **Approve & Create Billing Indent**.
3. Go to **Orders**, select **Dispense**, keep the batch on **FEFO (auto)**
   and select **Dispense**.

## 5. Take payment (billing)

1. Go to **Billing** and select **Cashier counter**.
2. Find the patient. Their open bills are listed.
3. Select **Collect**, choose the **Way of paying**, and collect.
4. Print the receipt from the done screen.

That is the whole journey. Each role's quick guide has the details:
[front office](/user-guides/front-office/), [doctor](/user-guides/doctor/),
[nurse](/user-guides/nurse/), [pharmacist](/user-guides/pharmacist/),
[billing](/user-guides/billing/).
