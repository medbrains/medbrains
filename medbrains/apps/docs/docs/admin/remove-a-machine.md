# Remove a machine

Remove a PC that is retired, lost, stolen or being moved to another hospital.

1. Go to **Admin** → **Machines**.
2. Find the machine and select **Remove**.
3. Read the question and select **Remove**.

MedBrains says **Machine removed. Its access ends within 30 seconds.** In
tests it ended in one to two seconds. Removing the machine also ends any copy
of its key someone may have taken.

The removed PC shows **Cannot reach the main machine**:

![A removed PC that can no longer reach the main box](/img/os/node-after-removal.webp "After removal the PC cannot reach the main machine.")

To use it again, set it up and [join it again](/admin/join-a-machine/).
