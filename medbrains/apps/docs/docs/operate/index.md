# Operate

For the people who keep a MedBrains server or OS box running.

- [Keys and secrets](/operate/keys/): every key a server holds, where it
  lives, and what to do if one is lost or stolen.
- [Release signing](/operate/release-signing/): what signs a release, the
  offline update roots, the key ceremony and the compromise runbook.
- [Recovery](/operate/recovery/): the recovery key prompt, TPM lockout, a
  failed update, the support console, a lost machine.
- [Releases and support](/operate/releases/): versions, branches, security
  fix deadlines, rollout rings and support dates.
- [Troubleshooting](/operate/troubleshooting/): common problems on the box,
  the server, backups and devices.
- [Backups and restore](/admin/backups/) and [updates and rollback](/admin/updates/)
  are in the admin guide.

Developers can also read the [CI/CD reference](/developer/reference/ci-cd/)
and the [environment variables](/developer/reference/env-vars/).
