# MedBrains documentation

MedBrains is software that runs a whole hospital: registration, OPD, wards,
pharmacy, lab, radiology and billing. These pages explain how to use it, set
it up and build on it. Choose where to start.

<AudienceCards />

New here? Read [what MedBrains is](/get-started/what-medbrains-is/), then
follow [your first patient, end to end](/get-started/first-patient-end-to-end/).

You see only the menus and buttons your role allows. If a page describes
something you cannot find, ask your hospital administrator for access.

Press <kbd>Ctrl</kbd> + <kbd>K</kbd> (or <kbd>⌘</kbd> + <kbd>K</kbd>) to search.
