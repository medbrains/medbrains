# MedBrains 3.33.0

**Release date:** not yet released. **Licence:** AGPL-3.0-only, or a commercial licence; the client SDKs stay Apache 2.0.

The first versioned release. Everything before it was built without version
numbers; this page summarises what 3.33.0 contains. The source is
[`CHANGELOG.md`](https://github.com/medbrains/medbrains/blob/main/CHANGELOG.md).

## Upgrade notes

- Database migrations apply automatically when the server starts. **Take a
  backup first.**
- After upgrading, check notifications. A hospital whose email or AI settings
  name a secret in an old format is asked to re-enter it.
- Hospitals that bill a module at the counter can leave its automatic charges
  off; the daily unbilled-orders check skips those modules.

## Latest changes

### Security

- Signing a clinical document asks you to confirm who you are again, and
  anyone holding a signed print can check it by its QR code.
- Live board updates reach only the hospital they belong to. A deactivated
  account or revoked device loses its live notifications.
- Secret references in a hospital's settings are limited to that hospital.
- Single sign-on links to a local account only by a verified email.
- Dependency updates clear several security advisories.

### Clinical

- Every clinical record type can be signed, by its registered author.
- The lab receives its order, not the patient's whole visit.
- A code-blue page is delivered, or the screen says plainly that it was not.
- The next shift can find a returning patient and reprint the card.

### Billing

- Orders done but never billed are found daily and queued for the billing desk.
- Automatic charges that a clinical action cannot post are queued for
  attention instead of being lost.

### Operations

- Switching off a module also switches off its API, not only its menu.
- The OS box uses less memory on its screen.
- The OS data disk is encrypted, with every key accounted for, and extra
  machines join the main one by approval.
- The web app loads faster: charts, the editor and language packs load only
  when needed.

## What 3.33.0 contains

- **The hospital system:** registration and UHID, OPD with token queues, IPD
  and discharge, laboratory, radiology with PACS, pharmacy with NDPS and
  schedule controls, billing with online, UPI QR and card-machine payments,
  HR, and more.
- **One case sheet per patient,** signed clinical documents, and printing with
  signatures and DRAFT marks.
- **Country integrations, India first:** ABDM M1 to M3, Scan & Share, NHCX eligibility,
  pre-auth and claims, and UHI. FHIR bundles are checked against the official
  HL7 validator before they are sent.
- **Apps:** the web app, native iPhone and Android apps for staff and
  patients, and TV boards.
- **Hospital OS foundations:** a kernel for tenant-scoped work, configurable
  discharge flows, drug-interaction and critical-value changes with two-person
  approval, and connected vendor apps with a published extension protocol and
  SDKs.
- **Security and operations:** row-level security on every table holding
  hospital data, an append-only audit of every change and PHI read, backups
  sealed to an offline key with restore drills, and signed release artefacts
  with SBOMs and checksums.
