# Doctor quick guide

**Who:** doctors.

## Call a patient from the OPD queue

1. Go to **OPD Queue**. The **Queue** tab opens.
2. On the patient's row, select **Call patient**, then **Start
   consultation**, then **Open OPD visit**.
3. When you are done, select **Complete**. Use **No show** for a patient who
   does not come in.

There is no single "call next" button: you call each row. If someone else
called the patient first, the screen says so and refreshes the queue.

## Write the consultation

See [write and sign a consultation](/user-guides/doctor/consultation/).

## Write a prescription

1. In the visit, open **Prescriptions**.
2. Search for a drug by salt or brand name and pick it.
3. Set **Dose**, **Frequency**, **Duration** and **Timing**.
4. Select **Safety** to see allergy, interaction, duplicate and dose checks.
   To go past a serious warning, give an **Override reason**.
5. Select **Sign & save**, then **Print**.

**Repeat last prescription** and **Order sets** save typing.

## Mark a medicine "Buy outside"

Use this when the hospital does not stock a medicine. It is always your
choice: MedBrains never marks a line buy outside by itself.

1. Type the medicine name in the prescription search.
2. Choose **Buy outside: "&lt;name&gt;"** under the matches.
3. Fill **Medicine** and **Dose** (and **Strength**), then select **Add as buy
   outside**.

The line prints as "Buy from outside the hospital". The pharmacy does not
dispense or bill it.

## Order a lab test

See [order a lab test and read the result](/user-guides/doctor/order-a-lab-test/).

## Admit a patient

1. In the OPD visit, select **Admit to IPD**.
2. Choose **Department**, **Ward** and **Bed**, and select **Admit patient**.
3. Write orders from the admission's tabs: **Prescriptions**,
   **Investigations**, **Progress Notes**, **Diet**.

## Write the discharge summary

1. Open the admission and go to **Discharge Summary**.
2. Fill the diagnosis, course, treatment, follow-up and discharge medicines.
3. Select **Save**, then **Finalize**. The summary shows **Signed**.

Editing a signed summary removes the signature; the screen asks first.
