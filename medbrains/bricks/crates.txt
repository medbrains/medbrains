# Every workspace crate and its class, for the kernel / apps (bricks) / shell split.
# Read by scripts/check_brick_edges.py (make check-brick-edges); a crate with no line fails it.
#
#   kernel, base            technical base plate: nothing about a hospital department
#   shared-health-service   hospital-domain code that several bricks use; depends on no brick
#   brick:<id>              one brick's crate (ids from medbrains-core bricks.rs)
#   multi-brick:<ids>       one crate serving several bricks, until it is split
#   not-yet-brick:<id>      domain code with no brick switch yet
#   shell                   the server binary
#   tooling                 test and load tools, never in the production binary
#   native-os               device, desktop, edge and OS programs
#
# A class is a decision (docs/decisions/2026-11-23-crate-classes-and-brick-edges.md).
# Changing a line changes what the check forbids, so it needs the owner.
