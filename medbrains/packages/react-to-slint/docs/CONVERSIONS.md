# React + Mantine to Slint: conversions

Generated by `bin/conversions-doc.mjs` from `src/mapping.json` (mapping version 9), `src/mantine-defaults.json`, `src/slint-reference.json` and the kit's own declarations. Do not edit by hand: change the tables and regenerate. Counts are uses in `apps/web/src` (`bin/usage.mjs`).

Sources: Mantine 9.3.2 (`node_modules/@mantine/*`, https://mantine.dev and its LLM pages https://mantine.dev/llms.txt), Slint 1.18 (reference https://releases.slint.dev/1.18.0/docs/slint/reference/overview/; the 1.18.1 viewer compiles against it).

## How a value converts

Every value is written with the type the Slint property declares: builtin and std-widget types from the [Slint reference](https://releases.slint.dev/1.18.0/docs/slint/reference/overview/), kit types parsed from `preview/*.slint` (following `inherits`). Mantine's own default props, then the app theme's `components.<Name>.defaultProps`, then the seam wrapper's defaults apply before the source's props ([default props](https://mantine.dev/theming/default-props/)).

| Kind | Rule | Slint doc |
|---|---|---|
| length | number → px (Mantine `rem(n)` is n px at the 16 px root); `Npx`; `Nrem` × 16; theme key `xs`…`5xl` → `Tokens.space-*` (or `Tokens.font-*` for font sizes); `N%` only on width, height and preferred sizes; `auto`, `calc()`, `vh`, `var()` dropped | [numeric types](https://releases.slint.dev/1.18.0/docs/slint/reference/property-types/numeric-types/), [type conversions](https://releases.slint.dev/1.18.0/docs/slint/reference/language/type-conversions/) |
| colour | `c="red"` → `--mantine-color-red-text`, `red.6` → `--mantine-color-red-6`, `dimmed`, `var(--mb-*)` → the semantic token with the same light and dark value (`src/css-vars.json`, measured from the built app); raw hex and unmatched shades dropped | [colors and brushes](https://releases.slint.dev/1.18.0/docs/slint/reference/property-types/colors-and-brushes/) |
| enum | CSS keyword → Slint enum value, qualified (`LayoutAlignment.start`) so a property named `start` cannot shadow it; checked against the reference | [builtin enums](https://releases.slint.dev/1.18.0/docs/slint/reference/property-types/builtin-enums/) |
| int, float, bool, string | literal of the declared type; text → `@tr("English sentence", …)` | [strings](https://releases.slint.dev/1.18.0/docs/slint/reference/property-types/strings/), [translations](https://releases.slint.dev/1.18.0/docs/slint/guide/development/translations/) |
| image | a Tabler icon element → `@image-url("@medbrains-gui-kit/icons/<name>.svg")` drawn with `colorize` | [images](https://releases.slint.dev/1.18.0/docs/slint/reference/property-types/images/), [Image](https://releases.slint.dev/1.18.0/docs/slint/reference/elements/image/) |
| anything else | a typed `in` property for the view model | [properties](https://releases.slint.dev/1.18.0/docs/slint/reference/language/properties/) |

Theme scale (tokens.ts, mantine.ts → `preview/tokens.slint`): spacing 3xs 4, 2xs 8, xs 10, sm 12, md 16, lg 20, xl 24 px; font xs 13, sm 14, md 17, lg 19, xl 21 px; headings h1–h6 33/27/23/21/19/17 px; input heights sm 32, md 40, lg 48; button heights xs 24 … xl 64; radius 0 everywhere (Carbon); breakpoints xs 576 … xl 1408 px.

## Common props

| Prop | Slint |
|---|---|
| `data-testid` | `accessible-id` |
| `aria-label` | `accessible-label` |
| `title` | `accessible-description` |
| `key` | not converted: React list identity; Slint `for` tracks model rows itself |
| `className` | not converted: CSS module class: its layout declarations convert (docs/CONVERSIONS.md, Layouts), every other declaration is noted in the file |
| `classNames` | not converted: Styles API: styling comes from the kit and Tokens |
| `styles` | not converted: Styles API: styling comes from the kit and Tokens |
| `style` | not converted: inline CSS has no Slint equivalent |
| `ref` | not converted: DOM ref: moves to the Rust view model |
| `id` | not converted: DOM id: Slint addresses elements by name |
| `component` | not converted: polymorphic element swap: the kit decides the element |
| `role` | not converted: ARIA role: the kit sets accessible-role |
| `aria-hidden` | not converted: decorative: Slint exposes only elements with an accessible role |
| `aria-live` | not converted: Slint 1.18 sets live regions per element with accessible-live-region in the kit |
| `td` | not converted: Slint 1.18 Text has no text decoration |
| `flex` | not converted: CSS flex shorthand: use horizontal-stretch or vertical-stretch in the kit |
| `display` | not converted: CSS display: use hiddenFrom/visibleFrom or a condition |
| `pos` | not converted: CSS positioning: Slint lays out by layouts, not offsets |
| `onSubmit` | not converted: form submission moves to the Rust view model |
| `type` | not converted: HTML input or button type: the view model decides what submit does |
| `size` | not converted: this component has no size variants in the kit |
| `variant` | not converted: this component has no variants in the kit |
| `radius` | not converted: Carbon corners are 0 in the theme (tokens.ts radius), so radius has no effect |
| `shadow` | not converted: elevation comes from the kit's surface tokens |
| `withinPortal` | not converted: portals are web-only: Slint draws popups in the window |
| `autoComplete` | not converted: browser autofill is web-only |
| `inputMode` | not converted: virtual keyboard hint: set input-type in the kit |
| `onBlur` | not converted: focus-out handling moves to the Rust view model |
| `onFocus` | not converted: focus handling moves to the Rust view model |
| `onKeyDown` | not converted: keyboard handling: FocusScope key-pressed in the kit |
| `required` | not converted: validation moves to the Rust view model |
| `withAsterisk` | not converted: required marker: the kit's label shows it from the view model |
| `maxLength` | not converted: input length limits move to the Rust view model |

## Layouts

- **Stack** → `VerticalLayout` with `alignment: start` (CSS flex-start; Slint's default would stretch).
- **Group** → `HorizontalLayout`, cross axis centred. Mantine's Group wraps when its row overflows; Slint's [FlexboxLayout](https://releases.slint.dev/1.18.0/docs/slint/reference/layouts/flexboxlayout/) reports a one-column preferred width inside a row, so it would wrap where the web does not. The one case that differs is a Group too wide for its row.
- **SimpleGrid / Grid** with written-out children → [GridLayout](https://releases.slint.dev/1.18.0/docs/slint/reference/layouts/gridlayout/): compile-time row and column per child, equal columns, `Grid.Col span` as `colspan`; a responsive `cols`/`span` becomes one GridLayout per breakpoint range under `if`. Over a list (`.map`) → rows of `cols` equal cells (`for grid-row … for grid-col`), never widths read from the grid (a binding loop).
- **Flex** → `HorizontalLayout`, or `FlexboxLayout` with `wrap="wrap"`.
- **CSS modules** (`className={classes.x}`): plain `.class` rules convert width/min/max sizes, `min(Npx, 100%)`, flex grow, gap, padding, justify-content, align-items, token colours, font size and weight, text-transform and a card's left accent; every other declaration is noted in the file.

## Accessibility (WCAG 2.2 AA)

Every interactive kit component sets `accessible-role` (a test fails otherwise), takes its accessible label from its label, text, placeholder or `aria-label`, and reports `accessible-value`/`accessible-checked` where it applies, with `accessible-action-default` (and increment/decrement on numbers). Each has a [FocusScope](https://releases.slint.dev/1.18.0/docs/slint/reference/keyboard-input/focusscope/) in reading order with a 2 px focus ring (`FocusRing`), Enter/Space activation, Escape on modals, 24 px minimum targets, field errors as `accessible-description`, and state shown by a mark or weight, not colour alone. `bin/a11y-audit.mjs` counts converted interactive elements without a name. [Slint accessibility properties](https://releases.slint.dev/1.18.0/docs/slint/reference/common/).
