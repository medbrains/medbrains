# npm audit, 2026-11-08

What `pnpm audit` reports across every JavaScript lockfile in the repo, what was fixed, and why
the rest is left. Decision row: `docs/DECISIONS.md`, Security and releases, 2026-11-08.

## How to repeat it

```sh
cd medbrains
pnpm audit --prod --json      # what the CI gate sees (security.yml: --prod --audit-level=high)
pnpm audit --json             # dev dependencies too
pnpm why -r <package>@<version>   # which workspace package pulls it in
cd ../website && pnpm audit --json
cd ../r8r/editor-ui && npm audit --package-lock-only --json
```

`pnpm audit` honours `auditConfig.ignoreGhsas` in `pnpm-workspace.yaml`; to see everything,
run it once with that block removed. Its `paths` list is truncated to a few entries per
advisory, so `pnpm why -r` is the source for which package pulls a version in.
